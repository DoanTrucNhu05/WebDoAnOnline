# 🍔 OnlineFoodShop

Website bán đồ ăn trực tuyến được xây dựng bằng PHP và MySQL.

## ✨ Chức năng

### Khách hàng
- Đăng ký / đăng nhập
- Xem và tìm kiếm sản phẩm
- Thêm sản phẩm vào giỏ hàng
- Đặt hàng
- Xem lịch sử mua hàng
- Theo dõi trạng thái đơn hàng

### Admin
- Quản lý sản phẩm
- Quản lý danh mục
- Quản lý khách hàng
- Khóa / mở khóa tài khoản
- Quản lý đơn hàng
- Cập nhật trạng thái đơn hàng

## 🛠️ Công nghệ

- PHP
- MySQL
- HTML / CSS / JavaScript
- Bootstrap 5
- Git / GitHub

## ⚙️ Cài đặt

- Clone project về máy.
- Đặt project vào thư mục `www` của VertrigoServ.
- Tạo database `OnlineFoodShop` và import file SQL.
- Cấu hình database trong `config/db.php`.
- Truy cập `http://localhost/WebDoAnOnline/`.
